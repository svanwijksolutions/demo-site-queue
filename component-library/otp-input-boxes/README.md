# OTP input boxes (visuele demo)

Vier monospace cijfervakjes met een knipperende cursor die automatisch vullen met een slide-up animatie en daarna weer leegmaken, in een lus. Puur decoratief/illustratief, geen echte invoer.

## Wanneer gebruiken

Als illustratie bij uitleg van een inlog- of verificatieproces (bijv. op een "hoe werkt het"-pagina), niet als een daadwerkelijk werkend formulierveld. Voor een echt OTP-invoerveld is losse toetsenbord- en focus-logica nodig die hier niet in zit.

## Hoe te gebruiken

1. Kopieer de markup uit `otp-input-boxes.html`.
2. Kopieer `otp-input-boxes.css`, pas de accentkleur (`--otp-accent`) aan.
3. Kopieer `otp-input-boxes.js`. Aantal vakjes staat vast op 4 (`N`), snelheid via de timer-drempels bovenin.
